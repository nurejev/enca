# ENCA beta 25374 — original policy names

Implemented on beta from `6b53c81` (25373). Waiting for production item **209**. No push, deployment or live tenant operation.

## 1. Change

The workspace naming helper replaced CA-prefixed policy names with a generated action/persona title, such as `MFA · Global`, while leaving `(UP)` names intact. The original name was shown only as a smaller subtitle. Distinct CA000 and CA003 policies could therefore share the same prominent title.

The helper has been removed. The Policies list, detail inspector and guided rollout now use the original model name from the tenant's `displayName`, preserving prefixes, CA numbers, spacing, punctuation and versions. Redundant name subtitles are removed. Long rollout names wrap within the existing column. Cards, full details and the settings matrix already used original names and retain that behavior. No policy data or tenant names are rewritten.

## 2. Passed validation

1. **104/104 existing offline tests** pass. Evidence: `tests-25374.txt`.
2. Local Edge acceptance at **1440px/light** and **390px/dark**, external traffic blocked. Five synthetic policy names cover two formerly identical generated MFA titles, `(UP)`, `(NEW)`, a long versioned name and a custom name containing punctuation and HTML-significant characters.
3. Each list button and inspector heading exactly matches the fixture's original name. Full-detail headings retain that name. No duplicate name subtitle remains. Searching by the full CA003 prefix selects the correct policy.
4. Cards and Matrix retain the full names. Selecting all five policies and opening rollout preserves every exact name; long names wrap without overflowing the selection container.
5. Zero page exceptions. Desktop and mobile screenshots were visually inspected. Evidence: `policy-names-25374.json`, `policy-names-desktop-25374.png`, `policy-names-mobile-25374.png`.
6. Toolbar order, plain-text checks, JavaScript syntax and whitespace checks pass. Build/cache keys, T01 and T40 versions, changelog and queue 209 are updated together.

## 3. Pending / limitations

Live tenant, other browsers and screen-reader acceptance were not run. Existing production acceptance gates remain open. This is a local rendering correction and adds no tenant requests or permissions.
