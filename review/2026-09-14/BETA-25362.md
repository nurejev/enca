# Beta 25362 — approved sidebar colours

Date: 2026-09-14. Scope: shared sidebar appearance.

Implements the approved colour mockup: dark branded sidebar in Light mode; a lightly brand-tinted sidebar with dark branded text in Dark mode. Selected items use the accent in Light mode and the deep brand colour in Dark mode. Auto follows OS changes. Colours also apply to the collapsed sidebar and mobile drawer. Native scrollbar colour scheme matches the sidebar. Keyboard focus uses a contrasting inset outline, including on the selected item.

The palettes derive from the existing active brand variables, without hard-coded green or purple hues. Navigation geometry and behavior are unchanged. No tool version was bumped because this changes shared chrome only; the app build and asset cache versions are 25362.
