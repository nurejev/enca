# Beta 25402 — Overview and connection menu

Promotion item 230 now covers builds 25401–25402.

## Changes

1. Appearance is labelled Theme.
2. Guided rollout and Changes appear as full tool cards.
3. Permissions in this session has its own workspace and persistent tab; the original refresh, consent and revocation handlers remain in use.
4. Overview includes all 24 primary tools in individually collapsible groups, with Collapse all / Expand all.
5. The account menu shows the configured app client ID, registration display name, registration ownership and owner tenant ID. Local registration ownership is compared with the active tenant ID. External multitenant classification requires the Graph signInAudience value. An external owner is identified by its tenant ID; no tenant display name is inferred from the app's publisher or authority URL.

Metadata is read from the current tenant's service principal by appId. Only silent acquisition with the existing scopes is used; lookup failure does not trigger consent and is shown as unavailable. Demo explicitly has no app connection.
