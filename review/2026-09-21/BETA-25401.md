# Beta 25401 — Workspaces

Date: 2026-09-21. Promotion queue: **230**. Production is unchanged.

## Delivered

The approved Workspaces concept is integrated into the real beta application: branded top bar, compact navigation rail, searchable tool library, recent tools and persistent tool tabs. Open tabs scroll horizontally on narrow screens; Overview stays available. Existing tool routes and confirmation steps remain in use.

Policies remains a viewer with Cards, List and Matrix. Details open centrally with six settings sections, original definition and the existing actions. Shared headings, action panels, form controls, cards and dialogs give the tools a consistent appearance while retaining tool-specific content.

The shell follows the actual signed-in/demo session, resets recent tools on tenant identity changes and sign-out, and keeps native sign-in, connection configuration, permission information and the beta ribbon. Branding uses the existing logo and palette settings, including live updates and light/dark contrast.

## Validation completed

- 201 offline tests passed; no failures or skipped tests.
- Toolbar ordering: 34 tool screens, 33 toolbars; all declared slots correct.
- Plain-text checks, JavaScript syntax and diff whitespace checks passed.
- Browser navigation: all 23 primary destinations; 25 responsive cases across 1440, 1024, 736, 390 and 320 pixels.
- Tool layouts: 33 reachable screens in desktop/light and mobile/dark, 66 cases total; 44 subtab visits. No uncaught browser errors.
- Policy details: centered on desktop/mobile, six sections, nested dependency dialog, documentation action, focus restoration, Escape, Close and backdrop dismissal, Cards and List entry points.
- Branding: four viewport/theme combinations, wide custom logo, palette and live native branding-form apply.
- Session behavior: original signed-out page plus simulated Graph login, same-name/different-ID tenant switch, sign-out and demo re-entry. This is browser fixture evidence, not a live tenant authentication test.

Evidence: [navigation](workspaces/shell-validation.json), [layouts](workspaces/layout-validation.json), [sessions](workspaces/session-validation.json).

- Live tenant sign-in, real data loading and tenant write workflows were not exercised. Existing authentication configuration and action handlers were retained.
- CIS is unavailable in demo; its tenant access gate was not bypassed.
- Local container verification could not run because the Docker daemon is not running. The beta push triggers the existing CI workflow.
- This report records pre-publication validation. Deployment status and the public build must be checked after push; local browser checks alone do not establish successful publication.

## Reproduce

Serve the repository locally on port 8774. With Playwright installed (or PLAYWRIGHT_MODULE pointing to its installation), run tools/workspaces-browser.cjs, tools/workspaces-layout-browser.cjs and tools/workspaces-session-browser.cjs. Browser suites block external tenant traffic. Run node --test tools/*.test.cjs, tools/check-toolbar-order.js and tools/check-plain-text.js for offline checks.
